### **📌 Summary of the Authentication Program**  

This is an **authentication system** built with **Node.js**, **Express**, **MongoDB (Mongoose)**, and **JWT (JSON Web Token)** for user registration and login.  

---

### **🛠️ Tech Stack & Extensions**

- **Node.js**: Backend runtime environment  
- **Express.js**: Web framework for handling API routes  
- **Mongoose**: MongoDB ODM (Object-Document Mapping)  
- **bcrypt**: Password hashing for security  
- **jsonwebtoken (JWT)**: Token-based authentication  
- **dotenv** (Recommended): To store sensitive data like `SECRET_KEY` in a `.env` file

### **📌 API Routes**
| Method | Endpoint       | Description |
|--------|--------------|-------------|
| `POST` | `/register`  | Registers a new user with hashed password |
| `POST` | `/login`     | Authenticates user, returns a JWT token |

---

### **📌 How It Works**
1. **User Registration (`/register`)**  
   - Receives `username`, `email`, and `password` from request body.  
   - Hashes the password using **bcrypt** before saving.  
   - Saves the user to **MongoDB** using **Mongoose**.  

2. **User Login (`/login`)**  
   - Finds the user by email in **MongoDB**.  
   - Compares the entered password with the stored hashed password.  
   - If valid, generates a **JWT token** (valid for 1 hour).
